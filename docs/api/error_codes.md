# Standardized API Error Codes

- `ERR_NOT_FOUND`: Resource or lot identifier does not exist.
- `ERR_UNAUTHORIZED`: Invalid or expired authentication token.
- `ERR_RATE_LIMITED`: Request rate exceeds threshold.
- `ERR_UPSTREAM_TIMEOUT`: Downstream mapping service timed out.
- `ERR_INVALID_COORDINATES`: Latitude or longitude outside valid geographic bounds.
