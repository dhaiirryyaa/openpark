# Edge Hardware Simulators Guide

OpenPark includes simulated edge hardware nodes in `backend/simulators/`:
- Ultrasonic bay sensors (`ground_sensor_node.py`)
- ANPR boom barriers (`boom_barrier_gate.py`)
- CCS2 EV chargers (`ev_charger_kiosk.py`)
- LoRaWAN gateways (`lorawan_gateway.py`)
- Traccar GPS streams (`traccar_device_mock.py`)
