# Internationalization (i18n) & Localization Guide

OpenPark supports multiple Indian regional languages and international locales:
- `en`: English (Default)
- `kn`: Kannada (Bengaluru Local)
- `hi`: Hindi
- `ta`: Tamil
- `te`: Telugu
- `es`, `fr`, `de`, `ja`: International Locales

## Adding New Language Keys
Add key-value string pairs in `app/i18n/<locale>.json`. Ensure all keys match the English reference schema.
