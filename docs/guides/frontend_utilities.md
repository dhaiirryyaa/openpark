# Frontend Utilities Reference

OpenPark provides ES6 utility modules in `app/js/utils/`:
- `geo.js`: Haversine distance and compass bearing.
- `formatters.js`: INR currency and duration formatting.
- `storage.js`: LocalStorage wrapper with memory fallback.
- `debounce.js`: Timing wrappers.
- `haptics.js`: Vibration feedback for mobile touch devices.
- `clipboard.js`: Secure clipboard text copy.
