# OpenPark Platform v2.6.0 Release Notes

### Major Additions
1. **Multilingual i18n Core**: Kannada, Hindi, Tamil, Telugu, English, Spanish, French, German, Japanese language bundles.
2. **Algorithms Suite**: Dijkstra router, Haversine distance matrices, occupancy decay models, Kalman GPS filter, and surge pricing.
3. **Edge Simulators**: Full virtual testbed for ultrasonic sensors, ANPR barriers, EV kiosks, and LoRaWAN gateways.
4. **Micro-Animations**: Ripple touch effects, shimmer loading states, radar beacons, and spring physics.
5. **Full Unit Test Suite**: Comprehensive coverage across all algorithms, validators, and client SDKs.
